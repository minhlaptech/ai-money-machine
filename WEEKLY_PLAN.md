## 🤖 AI AGENT PROTOCOL

### Mỗi lần chat "tiếp tục", AI sẽ:

1. **Đọc** `EXECUTION_LOG.md` → biết đã làm gì
2. **Đọc** `LAUNCH_CHECKLIST.md` → biết cần deploy gì
3. **Kiểm tra** ngày trong tuần → chọn task phù hợp
4. **Tạo content** phù hợp với schedule
5. **Cập nhật** log và kế hoạch
6. **Commit** tất cả thay đổi

### Priority Queue:
1. 🔴 **Urgent**: User requests, bug fixes
2. 🟠 **High**: Revenue-generating content (gigs, products, outreach)
3. 🟡 **Medium**: Growth content (blog, YouTube, social)
4. 🟢 **Low**: Optimization, analytics, planning
