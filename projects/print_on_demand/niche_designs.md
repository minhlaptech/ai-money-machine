   - Products: T-shirt, mug

   - Products: Mug, poster, t-shirt

6. **"sudo make me a sandwich" — Linux command humor**

   - Products: T-shirt, sticker

7. **Keyboard shortcut art**: Ctrl+Z (Undo my career choices)
   - Style: Keyboard key illustration
   - Products: T-shirt, sticker, poster

8. **"Hello World" in 10 programming languages**
   - Style: Rainbow gradient text
   - Products: Poster, t-shirt

9. **Git commit messages as poetry**

## 📋 PRODUCTION WORKFLOW

### Step 1: Design Creation
- Tool: Midjourney / DALL-E / Canva
- Resolution: Minimum 4500 x 5400 px (for print quality)
- Color mode: sRGB (convert to CMYK if needed)
- Format: PNG (transparent background for most)

### Step 2: Mockup Creation
- Use Printful's mockup generator (free)
- Or Placeit.net ($8/month) for premium mockups
- Create at least 3 mockup images per design

### Step 3: Listing Optimization
```
Title format: [Adjective] [Subject] [Product] | [Keyword] | [Gift Idea]
Example: "Funny Developer T-Shirt | Programmer Humor | Gift for Coder"

Tags (13 max on Etsy):
- Primary keyword
- Product type
- Audience
- Occasion (gift for, birthday)
- Style (minimalist, funny, vintage)
- Niche specific terms

Description (first 160 chars = SEO snippet):
Start with main keyword. Describe product.
Include sizing, care, shipping info.
```

### Step 4: Pricing Strategy
| Product | Cost (Printful) | Sell Price | Profit | Margin |
|---------|----------------|-----------|--------|--------|
| T-shirt | $12-15 | $24.99 | $10-13 | ~40% |
| Mug | $8-10 | $18.99 | $9-11 | ~50% |
| Poster | $5-8 | $16.99 | $9-12 | ~55% |
| Hoodie | $25-30 | $44.99 | $15-20 | ~35% |
| Sticker | $2-3 | $4.99 | $2-3 | ~50% |
| Phone case | $10-12 | $22.99 | $11-13 | ~48% |

### Step 5: Launch Plan
- Start with 20 designs in Niche 1 (Developer)
- Add 10 designs/week for first month
- Target: 100 active listings by end of month 1
- Use Etsy Ads: $1-3/day budget for top designs
- Pinterest marketing: Pin every design
