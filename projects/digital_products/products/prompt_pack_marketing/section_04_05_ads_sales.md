```

Price: $[X]
Target buyer: [IDEAL CUSTOMER PROFILE]
Main pain point: [PRIMARY PROBLEM]
Key benefit: [#1 OUTCOME]
Proof: [TESTIMONIALS / DATA / CASE STUDIES]

Landing page sections:
1. HERO: Headline + subheadline + CTA button
2. PROBLEM: Paint the pain (3-4 bullet points)

- Benefit-focused

- Social-proof-focused

Word count: 1500-2000 words total.
```

## PROMPT 77: VSL (Video Sales Letter) Script
```
Write a Video Sales Letter script for [PRODUCT/SERVICE].

Length: [5/10/15/20] minutes
Target viewer: [DESCRIBE]
Price point: $[X]
Primary objection: [BIGGEST RESISTANCE TO BUYING]

Structure (AIDA + Story):
1. HOOK (30 sec): Bold promise or shocking statement
2. PROBLEM (2 min): "If you're struggling with [X]..."
3. AGITATE (1 min): Cost of doing nothing
4. STORY (3 min): Origin story / discovery moment
5. SOLUTION (2 min): Introduce the product
6. PROOF (2 min): Results, testimonials, data
7. OFFER (2 min): What's included + bonuses
8. PRICE ANCHOR (1 min): Compare to alternatives
9. GUARANTEE (30 sec): Risk reversal
10. CLOSE (1 min): Final CTA with urgency

Include visual cues: When to show graphics, 
screenshots, testimonials on screen.
```
