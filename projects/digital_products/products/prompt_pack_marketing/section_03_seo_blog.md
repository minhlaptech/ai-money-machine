## PROMPT 46: SEO Blog Post Writer
```
Write a comprehensive, SEO-optimized blog post.

Target keyword: [PRIMARY KEYWORD]
Secondary keywords: [LIST 3-5]
Word count: [2000-3000]
Search intent: [Informational/Commercial/Transactional]
Audience reading level: Grade 8

Structure:
- Title tag (under 60 chars, keyword near front)
- Meta description (under 155 chars, include keyword + CTA)
- H1 heading with primary keyword
- Table of contents with anchor links
- 5-7 H2 sections with keyword variations
- H3 subsections where needed
- Introduction: Hook + keyword in first 100 words
- Body: Stats, examples, actionable steps, expert quotes
- Conclusion: Summary + clear CTA
- FAQ section: 3-5 related questions with schema-ready answers

Formatting rules:
- Short paragraphs (2-3 sentences max)
- Bullet points for lists
- Bold key phrases
- Include at least 2 internal link placeholders
- Include 3-5 external authority link suggestions
```

produce the article without additional research.

## PROMPT 48: Keyword Cluster Strategy
```
Create a keyword clustering strategy for a [NICHE] website.

Seed keyword: [KEYWORD]
Website authority: [New / Established / High Authority]
Content goal: [Traffic / Leads / Sales]

Generate:
1. Primary pillar topic (1 main keyword)
2. 5-8 cluster topics (supporting keywords)
3. For each cluster:
   - Target keyword + search volume estimate
   - Search intent
   - Suggested content type
   - Title suggestion
   - Internal linking plan (how it connects to pillar)
4. Content creation priority order
5. Estimated traffic potential per cluster
6. Quick-win opportunities (low difficulty, decent volume)

Present as a table + content map visualization description.
```

## PROMPT 53: Case Study Blog Post
```
Write a case study blog post using this information:

Client: [TYPE OF BUSINESS]
Challenge: [PROBLEM THEY HAD]
Solution: [WHAT WE DID]
Results: [SPECIFIC OUTCOMES WITH NUMBERS]
Timeline: [HOW LONG IT TOOK]

Structure:
1. Attention-grabbing headline with results
2. Executive summary (TL;DR)
3. Background: Who is the client?
4. The Challenge: What problem needed solving?
5. The Solution: Step-by-step what was done

Word count: 1500-2000 words.
```
