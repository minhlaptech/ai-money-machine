# SECTION 6: BRAND STRATEGY (10 Prompts)

## PROMPT 91: Brand Voice Guide Generator
```
Create a comprehensive brand voice guide for [BRAND NAME].

Industry: [INDUSTRY]
Target audience: [DESCRIBE]
Brand personality: [e.g., Professional but approachable]
Competitors: [LIST 2-3]

Generate:
1. Brand voice attributes (3 primary, 3 secondary)
2. Voice "Do's and Don'ts" chart
3. Tone spectrum: When to be more formal vs casual
4. Vocabulary guide:
   - Words we use (10-15 on-brand words)
   - Words we avoid (10-15 off-brand words)
5. Example copy in our voice:
   - Social media post
   - Email subject line
   - Error message
   - Customer support response
   - Landing page headline
6. How our voice differs from competitors
```

## PROMPT 92: Customer Persona Builder
```
Create a detailed buyer persona for [BUSINESS/PRODUCT].

Product: [DESCRIBE]
Price point: $[X]
Current customers (if known): [DESCRIBE]

Generate:
1. Persona name and photo description
2. Demographics (age, gender, location, income, education)
3. Psychographics (values, interests, lifestyle)
4. Professional profile (job title, company size, industry)
5. Goals and motivations (3-5)
6. Pain points and frustrations (3-5)
7. Buying triggers (what makes them decide to purchase)
8. Objections (what holds them back)
9. Information sources (where they learn, what they read)
10. Social media habits (platforms, frequency, behavior)
11. A typical day scenario (200 words)
12. How our product fits into their life

Create 2 distinct personas if the audience is diverse.
```

## PROMPT 93: Competitor Analysis Framework
```
Analyze [COMPETITOR NAME] from a marketing perspective.

Competitor: [NAME + URL]
My business: [YOUR BUSINESS]

Analyze:
1. Brand positioning: How do they position themselves?
2. Messaging: What's their core message?
3. Value proposition: What do they promise?
4. Content strategy: What types of content do they create?
5. Social media: Which platforms, frequency, engagement
6. SEO: What keywords do they rank for?
7. Pricing: How do they price? What tiers?
8. Strengths: What do they do better than us?
9. Weaknesses: Where do they fall short?
10. Opportunities: Gaps we can exploit

Provide actionable recommendations for each point.
```

## PROMPT 94: Unique Value Proposition (UVP) Creator
```
Help me craft a Unique Value Proposition for [BUSINESS].

What we do: [DESCRIBE SERVICE/PRODUCT]
Who we serve: [TARGET AUDIENCE]
Key differentiator: [WHAT MAKES US DIFFERENT]
Main benefit: [PRIMARY OUTCOME]
Current UVP (if any): [EXISTING]

Generate:
1. UVP framework: "We help [WHO] achieve [WHAT] by [HOW], 
   unlike [ALTERNATIVES] that [LIMITATION]"
2. 5 UVP variations (different angles)
3. One-sentence elevator pitch
4. 30-second elevator pitch
5. Tagline options (5, max 6 words each)
6. How to test and validate the UVP
```

## PROMPT 95: Brand Messaging Architecture
```
Create a messaging architecture for [BRAND].

Brand: [NAME]
Industry: [SECTOR]
Products/Services: [LIST]
Target segments: [LIST 2-3]

Build:
1. Brand promise (one sentence)
2. Mission statement (2 sentences)
3. Vision statement (1 sentence)
4. Core values (5, with explanations)
5. Messaging pillars (3-4 key themes):
   For each pillar:
   - Pillar name
   - Key message
   - Supporting points (3)
   - Proof points
   - Call to action
6. Messaging hierarchy:
   - Primary message (what we say first)
   - Secondary messages (supporting)
   - Tertiary messages (detailed)
7. Segment-specific messaging adjustments
```

# SECTION 7: ANALYTICS & RESEARCH (10 Prompts)

## PROMPT 101: Market Research Prompt
```
Conduct market research analysis for [PRODUCT/SERVICE] 
in the [INDUSTRY] space.

Analyze:
1. Market size and growth rate
2. Key trends (3-5 trends shaping the industry)
3. Target audience segments (3 segments with sizes)
4. Competitor landscape (map top 5-10 players)
5. Pricing benchmarks (what do similar products charge?)
6. Distribution channels (where do buyers find products?)
7. Barriers to entry
8. Opportunities and threats
9. Customer acquisition cost benchmarks
10. Recommended go-to-market strategy

Present findings in a structured report format 
with actionable recommendations.
```

```
Analyze the following customer feedback/reviews and 
extract actionable insights:

[PASTE 10-20 CUSTOMER REVIEWS OR FEEDBACK ITEMS]

3. Top 5 mentioned negatives (with frequency)
4. Feature requests (mentioned improvements)
5. Common use cases mentioned
6. Unexpected use cases
7. Competitor mentions
8. Quotable testimonials (best positive reviews)
9. Critical issues to address immediately
10. Recommendations for product/service improvements
11. Suggested responses for negative reviews

Format as an executive summary + detailed breakdown.
```
