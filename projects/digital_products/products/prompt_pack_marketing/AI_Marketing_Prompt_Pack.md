## 1. SOCIAL MEDIA CONTENT {#social-media-content}

### Instagram

**Prompt 1: Instagram Carousel Post**
```
Act as a social media strategist for the [INDUSTRY] industry.
Create a 10-slide Instagram carousel about [TOPIC].

For each slide, provide:
- Headline (max 8 words, attention-grabbing)
- Body text (max 30 words)
- Visual direction (what image/graphic to use)

Slide 1 must be a hook that makes people stop scrolling.
Slide 10 must include a clear CTA.
Tone: [Professional/Casual/Bold]
Target audience: [DESCRIBE AUDIENCE]
```

**Prompt 2: Instagram Reel Script**
```
Write a 60-second Instagram Reel script about [TOPIC] for a [INDUSTRY] business.

Structure:
- Hook (0-3 seconds): Pattern interrupt question or bold statement
- Problem (3-10 seconds): Relatable pain point
- Solution (10-40 seconds): 3 actionable tips
- CTA (40-60 seconds): Follow + save + share

Include on-screen text suggestions for each section.
Trending audio suggestion: [MOOD: upbeat/dramatic/educational]
```

**Prompt 3: Instagram Bio Optimizer**
```
Rewrite this Instagram bio for maximum conversions:

Current bio: [PASTE CURRENT BIO]
Business: [DESCRIBE BUSINESS]
Target customer: [DESCRIBE IDEAL CUSTOMER]
Main CTA: [WHAT SHOULD VISITORS DO?]

Requirements:
- Max 150 characters
- Include 1 relevant emoji per line
- Clear value proposition in first line
- Social proof element
- Specific CTA with action verb
- Include a branded hashtag

Provide 3 variations: Professional, Casual, Bold.
```

**Prompt 4: Weekly Content Calendar**
```
Create a 7-day Instagram content calendar for a [INDUSTRY] business.

For each day, provide:
- Content type (Post/Carousel/Reel/Story)
- Topic
- Caption (with relevant hashtags, max 30)
- Best posting time
- Engagement strategy (question to ask, poll idea, etc.)

Mix content types: 40% educational, 30% engaging, 20% promotional, 10% personal/behind-the-scenes.
Target audience: [DESCRIBE]
Brand voice: [DESCRIBE]
```

**Prompt 5: Hashtag Research**
```
Generate a hashtag strategy for a [INDUSTRY] Instagram account with [X] followers.

Provide:
- 10 niche-specific hashtags (under 100K posts)
- 10 medium-competition hashtags (100K-500K posts)
- 5 broad hashtags (500K+ posts)
- 5 branded/unique hashtags to own
- 3 trending hashtags relevant to [TOPIC]

Organize them into 3 "hashtag sets" I can rotate between posts.
```

### LinkedIn

**Prompt 6: LinkedIn Thought Leadership Post**
```
Write a LinkedIn post about [TOPIC] that positions me as an expert in [FIELD].

Structure:
- Hook line (max 12 words, makes people click "see more")
- Personal story or observation (2-3 sentences)
- 3-5 key insights or lessons
- Controversial or unexpected take
- Question to drive comments

Tone: Insightful but conversational. No corporate jargon.
Length: 1200-1500 characters.
```

**Prompt 7: LinkedIn Article**
```
Write a LinkedIn article (800-1200 words) about [TOPIC].

Target reader: [JOB TITLE/INDUSTRY]
Key message: [MAIN TAKEAWAY]

Include:
- Compelling headline with a number or question
- Opening story or statistic
- 3-5 subheadings
- Real-world examples or case studies
- Actionable takeaways
- CTA: [WHAT SHOULD READERS DO?]

SEO-optimize for LinkedIn search: include keywords [LIST KEYWORDS]
```

### Twitter/X

**Prompt 8: Twitter Thread (Viral Format)**
```
Write a 10-tweet thread about [TOPIC] designed to go viral.

Tweet 1 (Hook): Bold claim or surprising statistic that makes people stop scrolling. End with "🧵" and "A thread:"
Tweets 2-9: One insight per tweet, each under 280 characters. Use numbers, bullets, or single-line punches.
Tweet 10: Summary + CTA (Follow me for more, retweet if useful)

Topic: [TOPIC]
Audience: [DESCRIBE]
Include relevant emojis sparingly.
```

**Prompt 9: Twitter Content Repurposing**
```
I have this piece of content: [PASTE CONTENT - blog post, video transcript, etc.]

Create from it:
1. 5 standalone tweets (each under 280 characters)
2. 1 twitter thread (8 tweets)
3. 3 quote-tweet-worthy one-liners
4. 2 polls related to the topic

Each piece should work independently and drive engagement.
```

**Prompt 10: Twitter/X Bio & Profile**
```
Write a Twitter/X bio for a [ROLE] in the [INDUSTRY] space.

Include:
- What I do (clear value proposition)
- Who I help
- Social proof (if any: [ACHIEVEMENTS])
- Personality element
- CTA or link reference

Max 160 characters. Provide 5 variations.
```

## 2. EMAIL MARKETING {#email-marketing}

**Prompt 26: Welcome Email Sequence**
```
Write a 5-email welcome sequence for new subscribers to a [BUSINESS TYPE] email list.

Subscriber joined because: [LEAD MAGNET/REASON]
Goal of sequence: [BUILD TRUST → FIRST SALE]
Product/Service to sell: [DESCRIBE]
Price point: $[X]

For each email, provide:
- Subject line (+ 2 alternatives)
- Preview text
- Email body (300-500 words)
- CTA button text
- Send timing (Day 0, Day 2, etc.)

Tone: [Friendly/Professional/Bold]
```

**Prompt 27: Sales Email**
```
Write a sales email for [PRODUCT/SERVICE] priced at $[X].

Target reader: [DESCRIBE IDEAL CUSTOMER]
Main pain point: [WHAT PROBLEM DOES IT SOLVE?]
Key benefit: [#1 OUTCOME THEY GET]
Urgency element: [DEADLINE/SCARCITY/BONUS]

Structure:
- Subject line that gets >40% open rate (+ 3 alternatives)  
- Hook: Relatable problem
- Agitation: Why this problem costs them money/time
- Solution: How your product solves it
- Proof: Testimonial or statistic
- CTA: Clear, specific action
- P.S.: Additional incentive

Length: 300-400 words max.
```

## 3. SEO & BLOG CONTENT {#seo-blog-content}

**Prompt 46: SEO Blog Post**
```
Write a comprehensive, SEO-optimized blog post about [TOPIC].

Target keyword: [PRIMARY KEYWORD]
Secondary keywords: [LIST 3-5]
Target word count: [2000-3000]
Search intent: [Informational/Commercial/Transactional]

Structure:
- H1: Include primary keyword naturally
- Introduction: Hook + keyword in first 100 words
- H2s: 5-7 sections with keyword variations
- H3s: Subsections where needed
- Include: Statistics, examples, quotes, actionable steps
- Conclusion: Summary + CTA
- Meta title: Under 60 characters
- Meta description: Under 155 characters, include keyword

Write for humans first, search engines second.
Readability level: Grade 8 or below.
```
